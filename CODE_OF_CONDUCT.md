# Code of Conduct

offscript adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone who takes part in this project (issues, pull requests, discussions, reviews, or any other project space) is expected to follow it.

## In short

- Be respectful and welcoming, whatever someone's experience level, background or identity.
- Critique code and ideas, not people.
- Give specific, useful feedback, and accept it gracefully.
- No harassment, insults, trolling, or publishing anyone's private information.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainer, [@SujalKrG](https://github.com/SujalKrG), privately through the contact details on that GitHub profile. If the issue involves the maintainer, you can report it to GitHub through the "Report content" option on any comment or the [GitHub abuse form](https://support.github.com/contact/report-abuse).

All reports are handled privately. The maintainer will act as described in the Contributor Covenant's enforcement guidelines: correction, warning, temporary ban, or permanent ban, depending on severity.
